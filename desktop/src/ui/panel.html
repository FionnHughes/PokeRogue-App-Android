PokéRogue

Quick Toggles:

Tools:

Run history sharing:

The same code as in the phone app. Leave empty to turn sharing off.

Settings sharing:

Every device that has shared its settings is listed. The one you pick is used on all of them; touch controls and vibration stay as each device has them. Another device shows up here once it has shared (on the phone: open Sync saves).

Miscellaneous:

PokéRogue is made by its volunteer team. This is an unofficial client: report problems here, not to them.

Built on Admiral-Billy's PokeRogue desktop app (MIT licence). The tools are other people's websites.
